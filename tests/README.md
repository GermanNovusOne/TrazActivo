# Especificaciones de pruebas

`specifications/` contiene comportamiento P0 independiente del framework. Al
seleccionar stack, cada escenario debe enlazarse a una prueba ejecutable y
evidencia de pipeline sin alterar su resultado obligatorio.

Todavía no se selecciona test runner ni se declaran métricas de cobertura:
ambos dependen del stack y `NFR-MAINT-001` mantiene objetivo TBD.
