# ADR-014: Infrastructure as Code

- Estado: Proposed
- Bloqueo: TBD-AZR-004
- Fecha de baseline: 2026-08-17

## Contexto

La infraestructura y sus versiones deben ser reproducibles y auditables. Las
alternativas declaradas son Bicep y Terraform.

## Decisión

Pendiente. No se crea implementación IaC hasta que DevOps cierre el estándar.

## Evidencia requerida

- Capacidades y experiencia del equipo.
- Gestión de estado, módulos, secretos y permisos.
- Soporte de recursos/SKU objetivo en Chile Central.
- Estrategia de ambientes, stamps, drift y rollback.
- Integración con la plataforma CI/CD que cierre `TBD-AZR-005`.

Fuente: PDD ADR-014, sección 44 y TBD-AZR-004/005.
