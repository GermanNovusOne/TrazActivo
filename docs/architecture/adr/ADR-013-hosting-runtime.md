# ADR-013: Hosting Runtime

- Estado: Proposed
- Bloqueo: TBD-AZR-001
- Fecha de baseline: 2026-08-17

## Contexto

Debe seleccionarse el hosting inicial para web/API/workers en Azure Chile
Central. Las alternativas declaradas son Azure App Service y Azure Container
Apps.

## Decisión

Pendiente. Sprint 0 no selecciona una alternativa.

## Evidencia requerida

- Perfil de cargas y operación.
- Disponibilidad real de SKU en Chile Central.
- Modelo de escalado, jobs, despliegue, observabilidad y costo.
- Prueba de concepto y pricing comparable.
- Impacto en aislamiento por stamp y operación del equipo.

Fuente: PDD ADR-013, matriz 05.3 y TBD-AZR-001/002.
